# 需求评审检查清单

适用于 `spec.md`。有 UI 时并入 `hf-ui-design` 检查项。

## 可测性

- [ ] 问题与方案从用户视角写清,非实现愿望
- [ ] 用户故事 / 验收标准可判定（第三方能说出通过/不通过）
- [ ] 覆盖失败路径与边界，不只有顺利路径
- [ ] 测试决策写明缝与「测试外部行为」原则

## 反幻觉

- [ ] 无未确认假设写成事实(假设在 `product/assumptions.md`)
- [ ] 模糊量词已量化或删除
- [ ] 实现决策中没有会过时失效的具体文件路径堆砌（原型决策片段除外）

## 完整与一致

- [ ] 与访谈 / `CONTEXT.md` 中的词汇一致
- [ ] 明确列出范围外事项
- [ ] 无与 ADR / CONTEXT 冲突的静默推翻
