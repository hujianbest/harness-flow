# 需求评审 Checklist

适用于 `spec.md`,或 `plan.md` 的需求章节。加载的 `ext-*` 扩展若声明了本层追加检查项,一并检查。

## 可测性

- [ ] 每条 FR 描述的是可观察的行为,而非实现方式或愿望
- [ ] 每条 FR 至少有一条 Given/When/Then 验收标准,且结果可判定(第三方能明确说出通过/不通过)
- [ ] 验收标准覆盖了失败路径与边界值,不只有 happy path
- [ ] 每条 NFR 有量化阈值、验证方式与**真实出处**(用户原话/既有 SLA/现存问题)

## 反幻觉

- [ ] 没有为填模板发明的需求、约束或数字;"不适用"处附有一句理由
- [ ] 没有把未经用户确认的假设写成事实(假设都在假设区并写明失效影响)
- [ ] 模糊量词(大量、快速、稳定、体验好)已全部量化或删除

## 完整与一致

- [ ] 与 frame.md 的意图一致,没有夹带 frame 之外的新范围
- [ ] 范围外显式列出;没有 FR 落在范围外,也没有范围内能力缺 FR
- [ ] 需求之间无冲突、无重复;粒度适中(一条 FR 只描述一个行为)
- [ ] 阻塞性开放问题已全部解决;残留的均已标注"非阻塞"
- [ ] (仅 spec.md)无设计泄漏:没有类名、接口签名、表结构、框架选型等 HOW 层内容
