# 代码评审 Checklist

对照实现、测试与已批准的 `spec.md` / `architecture.md` / tickets。**须自己重跑测试、自己读完整 git diff。** 并遵循 `hf-code-review` 双轴。加载的 `ext-*` 追加项一并检查。

## 证据与范围

- [ ] 评审者本人重跑相关测试且通过
- [ ] git diff 与当前票/任务一致,无范围蔓延(有则须已说明)
- [ ] 票的验收标准可在行为上核对

## 测试质量

- [ ] 测外部行为而非实现细节
- [ ] 覆盖边界与失败路径
- [ ] 无造假测试;mock 仅用于真实外部边界

## 符合度

- [ ] 遵循 architecture 模块边界与横切约定;偏离有记录
- [ ] 使用 CONTEXT 领域词汇命名
- [ ] 错误处理与声明的失败模式一致
